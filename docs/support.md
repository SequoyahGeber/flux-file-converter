# Flux support

Flux File Converter's native Mac and iPhone apps work entirely on the device. No Unraid connection, invitation, login or MFA is required. The website is a separate server converter with Cloudflare login and invitations.

Choose one file, select an output format and set a name. Convert locally, then use Save to… to choose a destination with the Mac save dialog or iPhone Files export picker. You can edit the name after conversion before saving. Select several regular files to create a ZIP. Choose Extract ZIP to folder to unzip. Originals stay untouched; an explicitly confirmed Mac save can replace an existing destination atomically.

Try a sample includes fictional PNG, DOCX, MP4, JSON and ZIP files. On Mac, choose the sample from the empty conversion workspace. On iPhone, tap Try a sample before choosing your own file. Samples exercise the real converter; there is no separate demo engine. Read Privacy & support offline on iPhone, or Settings → Privacy policy on Mac.

In the iPhone Files picker, Recents is a view of recently accessed files, not a separate storage folder. Files shown there can live in Downloads, iCloud Drive or another provider. Browse shows their actual folders. Selecting a PDF through Recents and saving a PNG in Downloads does not move the PDF. If a save picker asks to replace an existing file, choose a different name to keep both copies.

The local format screen describes actual support. DOCX PDF/HTML preserves supported fonts, emphasis, colors, basic tables and embedded images, with local pagination. Equations, fields, tracked changes and other unsupported inline/layout content report an error before a rich output is published. TXT/MD extraction removes formatting and can omit unsupported DOCX content, including equations. ODT/EPUB/HTML currently support text extraction only; EPUB follows the declared primary reading order and excludes navigation/nonlinear resources. Subtitle conversion preserves cue text and timing, normalizes indices/timestamps, and omits WebVTT positioning/comments; styled regions report an error. Codec/container compatibility is required for lossless media remux. Not every file type can be converted into every other type.

Local limits: 5 GB per media file and in total, 512 MB other files, 16 MB text, 24 megapixel images, 200 input PDF pages, one job at a time and a 10-minute cooperative deadline. CSV/TSV tables are limited to 1,000 columns, 100,000 rows and 1,000,000 cells. Formula-like text cells are prefixed with an apostrophe for safer spreadsheet use; numbers and booleans retain their meaning. DOCX embedded images share a 128 MB estimated decoded-memory budget. Image-only PDFs require OCR in another app before text extraction. ZIP creation and extraction are limited to 1 GB of contents. Creation stores highly compressible entries without compression when needed to keep the archive extractable. Extraction is limited to 2,000 entries and 200× expansion, with CRC checks; links and unsafe/duplicate paths are rejected. A cooperative deadline cannot interrupt every Apple framework operation immediately. Keep Flux open while converting. Backgrounding cancels active work.

On iPhone, Clear, a new file selection or restarting removes the previous temporary result. On Mac, Clear history or restarting removes temporary results; Recent files is the app’s session conversion history. Saved files and originals are never included in cleanup. Device storage is needed for a working copy and output; lossless formats can be larger than the input.

The separate website keeps its existing 5 GB eligible media / 1.9 GB other upload limits, 10-minute jobs, server queue and 30-minute inactivity expiry. Website batches wait for upload/job quotas and resume unfinished conversions; cancelling or retrying preserves completed results. The current tab remembers output choices across reloads without storing file contents or filenames in browser preferences. Electron/server structured table conversion is limited to 50 MB, 1,000 columns, 100,000 rows and 1,000,000 cells; duplicate/empty headers reject consistently. Numeric inputs that cannot retain precision reject before output publication; use quoted strings for exact identifiers or high-precision decimals. Native conversion does not contact it.

## Activity Monitor on Mac

The app and its main executable are named Flux File Converter. Native conversions run inside that process, including the linked media library, so their CPU and memory usage belongs to Flux. The sidebar uses Apple's WebKit, which macOS runs with separate system helpers. Flux does not launch separate command-line conversion workers. macOS controls its framework helper names and isolation.

In Activity Monitor, search for Flux to find the main process. The Energy tab shows energy information for apps and their processes; Energy Impact is a relative score. View → All Processes, Hierarchically shows parent/child relationships. See [Apple's energy guide](https://support.apple.com/guide/activity-monitor/view-energy-consumption-actmntr43697/mac) and [process guide](https://support.apple.com/guide/activity-monitor/view-information-about-processes-actmntr1001/mac).
